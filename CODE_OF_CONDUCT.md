# Code of Conduct

This project has adopted the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its code of conduct. The full text — including the pledge, expected standards, enforcement responsibilities, scope, and enforcement guidelines — is canonical at the link above.

## Scope

This Code of Conduct applies to all project spaces, including:

- The GitHub repository (issues, pull requests, discussions, code reviews, commit messages)
- Any official communication channel for the project
- When an individual is officially representing the project in public spaces

## Reporting

If you experience or witness behaviour that violates the Contributor Covenant, please report it to the project maintainer at **pkeenan87@users.noreply.github.com**. Reports will be reviewed and investigated promptly and fairly.

The maintainer is obligated to respect the privacy and security of the reporter.

## Enforcement

The maintainer will follow the **Community Impact Guidelines** described in section 5 of the [linked Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines) when determining the consequences for any action they deem in violation of this Code of Conduct.

Consequences range from a private written notice for first-time minor incidents up to a permanent ban from project spaces for sustained or severe violations.
